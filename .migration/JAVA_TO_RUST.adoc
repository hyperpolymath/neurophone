== Java/Kotlin → Rust Migration Guide

=== Policy

Java/Kotlin code should be migrated to Rust for: - Memory safety without
GC - Better performance - Smaller binaries

=== Migration Steps

[arabic]
. Create `+Cargo.toml+` project
. Convert Java classes to Rust structs/enums
. Replace JVM concurrency with Rust async/threads
. Remove pom.xml/build.gradle after migration
