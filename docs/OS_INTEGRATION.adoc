= NeuroPhone OS Integration Guide
:toc:
:toclevels: 3

This document describes how NeuroPhone integrates with Android *as deeply
as the platform allows for a non-system app*, plus the optional Termux
CLI path for users who prefer a terminal.

== Two install paths, one app

[cols="1,3"]
|===
|Path | When to use it

|*APK + home-screen widget*
|You want NeuroPhone to act like a regular phone app — tap an icon, see
 the widget, get notified. This is the recommended default.

|*Termux CLI* (`neurophone` command)
|You want to drive it from a terminal on the device, script it, or
 develop against it. Coexists fine with the APK.
|===

== Android integration surface

The APK plugs into Android via these standard system entry points:

[cols="2,4"]
|===
|Surface | Wiring

|Launcher icon
|`MainActivity` with `android.intent.action.MAIN` + `LAUNCHER`.

|Home-screen widget
|`NeurophoneAppWidget` (AppWidgetProvider) declared in `AndroidManifest.xml`,
 layout `res/layout/widget_neurophone.xml`, metadata `res/xml/neurophone_widget_info.xml`,
 configuration activity `NeurophoneWidgetConfigureActivity`.

|Foreground service
|`NeurophoneService` runs the sensor → LSM → ESN → bridge → LLM loop and
 holds a `PARTIAL_WAKE_LOCK`. Notification channel `neurophone_runtime`.
 Foreground type `dataSync`.

|Boot persistence
|`BootReceiver` watches `BOOT_COMPLETED` and `LOCKED_BOOT_COMPLETED`. The
 service restarts only if the user had it running before reboot
 (persisted in widget SharedPreferences).

|Voice / ASSIST
|`MainActivity` accepts `android.intent.action.ASSIST` so a long-press of
 the home button (where the OS allows it) opens NeuroPhone.

|Share sheet
|`MainActivity` accepts `ACTION_SEND` for `text/plain`, so any "Share"
 action that exposes text can be sent into a NeuroPhone query.

|Deep links
|`neurophone://query?q=...` URIs open MainActivity and pre-populate the query.

|Sensor stack
|Standard `SensorManager` listeners on TYPE_ACCELEROMETER, TYPE_GYROSCOPE,
 TYPE_MAGNETIC_FIELD, TYPE_LIGHT, TYPE_PROXIMITY at `SENSOR_DELAY_GAME`
 (~50 Hz). All processing is local.
|===

== Home-screen widget

The widget provides four interactions in a 3×2 cell:

. *Power toggle* — start / stop the foreground service.
. *Refresh* — re-read state and redraw.
. *Salience meter* — live progress bar driven by the service every 1 s.
. *Ask NeuroPhone* — opens MainActivity in query-input mode.

Add it: long-press home → Widgets → drag NeuroPhone widget.

State flow:

  NeurophoneService                                   Home-screen widget
  ─────────────────                                  ───────────────────
  computeSalience() ─► publishState() ─► SharedPreferences
                                                     ▲
                                  ACTION_REFRESH ────┘ render()

== Permissions

The APK requests:

* `BODY_SENSORS`, `HIGH_SAMPLING_RATE_SENSORS` — sensor stream
* `INTERNET` — only used when Claude fallback is enabled
* `FOREGROUND_SERVICE`, `FOREGROUND_SERVICE_DATA_SYNC` — long-running pipeline
* `POST_NOTIFICATIONS` — service-status notification (Android 13+)
* `RECEIVE_BOOT_COMPLETED` — restart pipeline after reboot if the user had it on
* `WAKE_LOCK` — keep CPU on the rare frames where 50 Hz would otherwise miss

== Install paths

=== Workstation → phone (one shot)

[source,bash]
----
./scripts/install-on-phone.sh                  # default arm64-v8a
./scripts/install-on-phone.sh --no-model       # skip ~700 MB model push
./scripts/install-on-phone.sh --uninstall      # remove
----

=== On-device Termux

[source,bash]
----
curl -fsSL https://raw.githubusercontent.com/hyperpolymath/neurophone/main/scripts/install-termux.sh | bash
----

=== Boot persistence (Termux side)

[source,bash]
----
# After installing the Termux:Boot add-on
mkdir -p ~/.termux/boot
cp scripts/start-on-boot.sh ~/.termux/boot/neurophone
chmod +x ~/.termux/boot/neurophone
----

== Uninstall

[source,bash]
----
# Workstation side (over ADB)
./scripts/uninstall.sh --adb

# On-device (Termux)
bash scripts/uninstall.sh
----

Both paths leave Android's per-app storage clean.
